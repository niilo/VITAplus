VITA+ v1.3.8 adopts the device-tested Vita3K-Plus experiment as the development
base. It keeps the Plus renderer and shaders and includes the focused NGS pool
allocation fix. The shared ATRAC9 call correction uses the API supplied by the
pinned decoder dependency.

Download the APK for your installed app:

- **VITAdev-v1.3.8-android-arm64.apk** updates VITAdev and the tested experiment.
- **VITA-Plus-v1.3.8-android-arm64.apk** updates the regular VITA+ app.
- **VITA-Plus-v1.3.8-linux-x86_64.AppImage** is the Linux x86_64 build.

Both APKs retain their existing package and signing key. Their version code is
1030800. Install over the existing app to retain its data.

Native and Android version labels now share the project version source.
Update links point to this repository. The previous master is preserved on
`archive/master-before-plus-promotion-20261024`; development continues from
the accepted Plus base.

The release includes verified APKs, matching native libraries, source and build
manifests, testing instructions and checksums. See TESTING.md for the matched
Jak and Uncharted scenes and the audio/loading checks. Device performance,
power and thermals are not claimed by this release.
